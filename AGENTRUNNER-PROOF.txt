AGENTRUNNER INTEGRATION PROOF
=============================

WHAT THIS PROVES: the chain runs end to end --
  orchestrator -> mission selection -> target resolution -> workspace isolation
  -> AgentRunner -> structured outcome -> baseline-aware testing -> validation
  -> verdict -> persistence.

WHAT THIS DOES NOT PROVE: anything about a language model. The agent here is a
DETERMINISTIC process applying a declared edit. It was chosen because no headless
coding agent exists on this machine, and because a reproducible run is what
proves a harness. Swapping it for a real coding agent is a configuration line and
touches no Core code.

TARGET REPOSITORY: a real git repository with real tests, one of which failed
before the run for a known reason (accented characters were not transliterated).
